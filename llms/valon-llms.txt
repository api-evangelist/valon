# Valon

> Valon is a technology-first residential mortgage servicing platform (New York, founded 2019; a16z-backed, $100M Series C in 2024, Ginnie Mae approved issuer). Its consumer business — servicing, lending, and insurance — publishes no public API. Valon's public developer surface is Gestalt (gestaltd.ai): an Apache-2.0, self-hostable platform for managing agentic tools and services that unifies REST/OpenAPI, GraphQL, MCP, and executable code behind one operation model, with an HTTP API, a Rust CLI, Go/Python/Rust/TypeScript SDKs, and an MCP endpoint.
